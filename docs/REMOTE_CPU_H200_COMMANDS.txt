一、联网CPU安装依赖
可从任意当前目录开始。推荐的--dependencies-only模式只安装/opt下的依赖、
工具链和离线运行资源，不要求项目或模型共享盘已经挂载，也不创建BASE项目目录。
先按会话提供的真实内网索引export SHORE_PIP_MIRROR和SHORE_PIP_MIRROR_HOST，
以下命令保留环境变量，不在公开文档写入平台内部DNS。pip安装均由现行bootstrap使用
env -u PIP_EXTRA_INDEX_URL -u PIP_INDEX_URL PIP_CONFIG_FILE=/dev/null的格式执行。
CPU不要求GPU、nvidia-smi或模型目录，先装Conda工具链以保证git/nvcc/编译器齐备。
Conda用NVIDIA cuda-12.8.1标签固定12.8补丁版本；不是安装GPU驱动。
Conda优先使用当前CONDA_EXE或PATH；找不到时检查原安装位置，不将旧项目目录继续作为源码路径。

推荐使用下列短入口，不再粘贴长heredoc。完整实现位于scripts/prepare_cpu_h200.sh。
它会明确打印阶段和失败原因。CPU实例的项目路径属于overlay，不妨碍这个依赖安装模式。
不带--dependencies-only的完整模式仍要求真实项目共享挂载，并额外同步仓库及准备测试包。

# 先按会话提供的值设置SHORE_PIP_MIRROR和SHORE_PIP_MIRROR_HOST。

  --dependencies-only \
  --index-url "${SHORE_PIP_MIRROR:?请先设置SHORE_PIP_MIRROR}" \
  --trusted-host "${SHORE_PIP_MIRROR_HOST:?请先设置SHORE_PIP_MIRROR_HOST}"

二、无网H200运行六公开宇宙

运行端需具有上面三个/opt完整环境目录，以及指定路径下的主项目和模型。
--dependencies-only不克隆主项目或test、不解压宇宙测试包；运行材料须另行准备就绪，
不能等到无网H200阶段再下载。仅为H200/SM90编译的环境不能直接给4090用。
项目固定路径是运行时的位置，不是CPU安装依赖的前置条件。

这一步不执行git、pip或Conda，不重新下载代码/模型。可以从任意目录启动，脚本会cd到PROJECT。
默认27b；可在执行前export SHORE_MODEL=35b/35b-fp8/122b/122b-fp8。
只允许MODELS.txt中规定的Qwen模型，397B已移除。若实际模型挂载另有路径，可显式export SHORE_MODEL_ROOT。
若新模型路径仍是overlay或空目录，先恢复共享挂载，不能靠mkdir得到另一实例已有模型。
Qwen短烟测可能只生成思考token；以实际生成token验证链路，不将空最终文本误判为模型未加载。
随后同一已加载服务完成六公开标准流程；实际分数/交卷质量由所用模型及策略决定。

本节运行方式：bash <<'H200'，粘贴下列脚本正文，最后单独一行H200。

#!/usr/bin/env bash
set -euo pipefail
umask 077

SHARED='/inspire/hdd/project/26-the-other-shore/fengkairui-25026'
PROJECT="$SHARED/DiscoverPhysics"
ENVROOT='/opt/shore-h200-cu128'
MODELROOT="${SHORE_MODEL_ROOT:-/inspire/hdd/project/26-the-other-shore/public/models}"
MODEL="${SHORE_MODEL:-27b}"
PY="$ENVROOT/.venv-trial/bin/python"
MPY="$ENVROOT/.venv-vllm-cu128/bin/python"

test -f "$PROJECT/shore_agent/agent.py"
test -d "$MODELROOT"
findmnt -T "$SHARED" -o TARGET,SOURCE,FSTYPE
findmnt -T "$MODELROOT" -o TARGET,SOURCE,FSTYPE
for path in "$SHARED" "$MODELROOT"; do
  case "$(findmnt -n -T "$path" -o FSTYPE)" in
    overlay|tmpfs|ramfs) echo "路径没有所需共享挂载：$path" >&2; exit 2 ;;
  esac
done
source "$ENVROOT/activate_h200_offline.sh"
cd "$PROJECT"
nvidia-smi
"$PY" /opt/shore-image-tools/verify_h200_cuda128.py --env-root "$ENVROOT" --timeout 300
"$PY" scripts/serve_model.py --model "$MODEL" --model-root "$MODELROOT" \
  --model-python "$MPY" --dry-run

# 模型仅加载一次：先真实生成，再复用同节点服务跑六公开；退出时清理服务。
"$PY" - "$PROJECT" "$MODELROOT" "$MPY" "$MODEL" <<'PY'
import json, subprocess, sys
from datetime import datetime, timezone
from pathlib import Path
from shore_agent.models import managed_model

project, root, model_python, model = sys.argv[1:]
stamp = datetime.now(timezone.utc).strftime('%Y%m%dT%H%M%S%fZ')
run = Path(project)/'results'/('h200-'+model+'-'+stamp)
run.mkdir(parents=True, exist_ok=False)
with managed_model(model, model_root=root, python_executable=model_python,
                   startup_timeout=900, log_dir=run/'model') as client:
    text = client.complete([{'role':'user','content':'Return the word ready.'}],
                           max_tokens=128, timeout=180)
    usage = client.last_response.get('usage', {})
    tokens = usage.get('completion_tokens', usage.get('output_tokens', 0))
    assert isinstance(tokens, int) and tokens > 0, '未获得真实生成token'
    print(json.dumps({'model':model,'generated_tokens':tokens,
                      'text':text[:300],'usage':usage}, ensure_ascii=False), flush=True)
    subprocess.run([sys.executable, '-m', 'development_worlds.runner',
                    '--worlds','1','2','3','4','5','6', '--model',model,
                    '--base-url',client.base_url, '--output',str(run/'six-public')],
                   cwd=project, check=True)
print('结果：'+str(run/'six-public'/'summary.json'))
PY

三、可选：指挥部九隐藏完整测试

此分支需要已可用的Docker/NVIDIA容器、可被docker image inspect识别的离线基础镜像
（其中已有/opt环境），以及指定路径下完整的test仓库和已解压H200测试包，并且四GPU空闲。
先停止六公开共享服务释放GPU。设置LOCAL_BASE_IMAGE为实际本地镜像tag/ID，不填写假sha256。
上述条件不是单纯安装Python依赖可创造的；若平台不支持嵌套Docker，应由平台提供等价隔离端。
下面是指挥部内部测试数据库，不是正式榜单，不需要虚构48小时正式截止时间。
代码与参数固定源来自当前测试包的同包SDK，source env_open_models.sh绑定RIFT_PUBLIC_ROOT到TESTROOT，
不要用另一份Git检出覆盖其profile所绑定的SDK字节。

#!/usr/bin/env bash
set -euo pipefail
umask 077

# 仅当H200节点已经支持Docker/NVIDIA容器，并已有本地离线基础镜像时执行。
: "${LOCAL_BASE_IMAGE:?先设置实际可被docker image inspect找到的本地基础镜像}"
BASE='/inspire/hdd/project/26-the-other-shore/fengkairui-25026'
TESTROOT="$BASE/shore-organizer-open-model-test-20261101"
ENVROOT='/opt/shore-h200-cu128'
MODEL="${SHORE_MODEL:-27b}"
MODELROOT="${SHORE_MODEL_ROOT:-/inspire/hdd/project/26-the-other-shore/public/models}"
PY="$ENVROOT/.venv-trial/bin/python"
source "$ENVROOT/activate_h200_offline.sh"
source "$TESTROOT/env_open_models.sh"
cd "$TESTROOT"
docker version
docker image inspect "$LOCAL_BASE_IMAGE" >/dev/null

RUNROOT="$TESTROOT/results/nine-$(date -u +%Y%m%dT%H%M%S)-$$"
mkdir -m 700 -p "$RUNROOT"
PUBLICROOT="$RUNROOT/participant"
"$PY" "$BASE/test/prepare_test_bundle.py" --bundle starter --target "$PUBLICROOT"
MANIFEST="organizer-smoke-$(date -u +%Y%m%dT%H%M%S)-$$.json"
cd "$PUBLICROOT"
"$PY" scripts/make_submission.py --model "$MODEL" --team-id organizer-demo \
  --submission-id "smoke-$(date -u +%Y%m%dT%H%M%S)-$$" --output "$MANIFEST"
"$PY" scripts/build_runtime_images.py --base-image "$LOCAL_BASE_IMAGE" \
  --manifest "$MANIFEST" --agent-tag shore-agent:organizer-smoke \
  --candidate-tag shore-candidate:organizer-smoke --output "$RUNROOT/image-ids.json"
cd "$TESTROOT"
AGENT_IMAGE="$("$PY" -c 'import json,sys; print(json.load(open(sys.argv[1]))["agent_image"])' "$RUNROOT/image-ids.json")"
CANDIDATE_IMAGE="$("$PY" -c 'import json,sys; print(json.load(open(sys.argv[1]))["candidate_image"])' "$RUNROOT/image-ids.json")"
"$PY" configure_runtime.py configure --profile profiles/internal-v9/profile.json \
  --output "$RUNROOT/site.json" --candidate-image-id "$CANDIDATE_IMAGE" \
  --model-root "$MODELROOT" --models "$MODEL" --gpu-devices 0 1 2 3
"$PY" configure_runtime.py preflight --profile "$RUNROOT/site.json" --output "$RUNROOT/preflight.json"
"$PY" configure_runtime.py model-smoke --profile "$RUNROOT/site.json" \
  --agent-image-id "$AGENT_IMAGE" --models "$MODEL" --output "$RUNROOT/model-smoke.json"
"$PY" contest_platform.py intake --db "$RUNROOT/internal.sqlite" --manifest "$PUBLICROOT/$MANIFEST" \
  --image "$AGENT_IMAGE" --submission-root "$PUBLICROOT" --team-id organizer-demo --internal-validation
"$PY" contest_platform.py work-once --db "$RUNROOT/internal.sqlite" --profile "$RUNROOT/site.json" \
  --run-root "$RUNROOT/runs" --worker-id organizer-check --internal-validation
printf '\n九隐藏内部测试资料：%s\n' "$RUNROOT"
