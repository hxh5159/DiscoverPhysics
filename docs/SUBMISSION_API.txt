攻坚组智能体提交规范 1.1.0（直接项目运行）

一、项目与逐宇宙交卷

攻坚组在自己的实际项目目录中开发，保留submission.json约定的启动入口。指挥部在测评
窗口接入九宇宙运行包，直接启动该项目当前代码和模型；不要求制作队伍容器或复制模型。
测评期间停止编辑代码、配置和所用权重。模型加载完成后，智能体在每个宇宙自动实验，
通过控制台提交该界law.py和claims.json。固定积分与评分由指挥部程序执行。

二、启动清单

    {
      "schema_version": "1.0.0",
      "submission_id": "team01-v1",
      "team_id": "team01",
      "version": "1.0.0",
      "entrypoint": ["python", "-m", "shore_agent.agent", "--model", "27b", "--model-path", "/inspire/hdd/project/26-the-other-shore/public/models/Qwen3.8-27B"],
      "models": [{
        "base_model": "Qwen3.8-27B",
        "path": "/inspire/hdd/project/26-the-other-shore/public/models/Qwen3.8-27B",
        "adaptation": "base"
      }]
    }

六个根字段必填，不接受未知字段。submission_id与team_id为不超过64字符的字母数字标识，
可含点、横线和下划线；version为本组版本说明。make_submission.py可从七预设生成小型
清单，默认使用model_catalog.json中的实际模型根；支持--model-root和--model-path。

entrypoint是直接执行的argv数组，不是shell命令字符串；不接受bash/sh包装入口。
工作目录是本次队伍实际项目根目录。可填实验环境Python绝对路径，或由指挥部通过
--agent-python指定python入口使用的解释器。新增模块和配置直接从本队项目读取，
不要求放进预设镜像。入口应使用已经安装好的依赖，不能在无网评测时临时下载。

每个模型必须声明白名单base_model与实际path。path可为项目内POSIX相对路径，或实例
中的Linux绝对路径；不接受..、反斜线、冒号、重复分隔符。旧/models/...声明保持兼容，
但不是当前默认路径。revision、sha256、adaptation可选；adaptation为base、quantized、
sft、rl或other。完整检查点或底座与适配器的实际加载由本队入口完成并提前自测。
声明模型名称不证明来源或显存可用；清单不会自动修改权重或重新训练模型。

三、自动运行环境与固定指令

每界由指挥部运行器设置RIFT_CONSOLE_URL、RIFT_SESSION_TOKEN、RIFT_OUTPUT_DIR。
控制台只授权当前会话，合法本机HTTP JSON通信属于官方通道。智能体使用rift.Console
完成mission、observe、launch、archive、save_draft和submit。law.py仍为不联网、不读写
文件的纯数学程序；不把智能体工作流写入law.py。

从本队项目根目录，由指挥部执行：

  python scripts/evaluate_submission.py --organizer-root /指挥部运行包目录 \
    --manifest submission.json --output /指挥部结果目录/本次运行

可用--project-root明确项目目录，--profile指定指挥部配置，--agent-python指定实际解释器。
--check-only只检查入口与配置，不启动模型或给科学分数。输出目录须为新目录。
运行包由外界接入，公开入口本身不包含九宇宙模拟器、验证真值或评分答案。

四、公开自检

  python scripts/validate_submission.py submission.json
  python scripts/validate_submission.py submission.json --root . --check-files

默认只检查JSON、白名单和路径格式，不运行入口、不读取权重。--check-files才检查
声明的相对文件和实际Linux绝对路径；如填sha256则读取内容校验，可能耗时较长。
旧/models/...声明留待旧部署环境检查。文件/目录摘要算法由rift.submission.artifact_digest
规定。examples/agent.py会转发到实际基础智能体；它不是零加速度替代方案。

五、计分与材料边界

六公开环境允许反复开发、自测和生成训练数据，不计入正式榜单。九隐藏每次新建独立
会话与配额，完成整轮后反馈总分和各宇宙总分，不拼接不同运行的单界最高分。
九隐藏观测、对话、候选、日志、新记忆和更新权重赛中不返还，由指挥部保留。
四个测试窗口的次数由指挥部管理。截止按成功受理时间；基础设施故障保留本次版本，
修复后重评。模型权重/代码不因接入环境被自动替换，测评期间不得人工干预。
